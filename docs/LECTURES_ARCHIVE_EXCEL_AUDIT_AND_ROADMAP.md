## 3. الخيارات المعمارية المقترحة لرفع كفاءة التصفح والوصول (Navigability & Findability)

### أ. الهيكلة ثلاثية المسارات (3-Pillar Information Architecture)
تقسيم رأس صفحة المحاضرات إلى ثلاثة مسارات كبرى تلبي احتياجات مختلف الزوار:
1. **مسار المواسم السنوية الحولية:** (عاشوراء ومحرم، صفر، شهر رمضان، الجمعة) مرتبة زمنياً بكل عام.
2. **مسار الدروس والمناهج المستمرة (Playlists / Courses):** (التفسير، العقائد، الفلسفة ونظرية المعرفة، الموعظة الأسبوعية)، تُعرض كمساق تدريبي متسلسل بالحلقات.
3. **مسار البرامج والحوارات الإعلامية:** (إشراقات، إنارات، فصل الخطاب، الحوارات والندوات المفتوحة).

### ب. شريط عقود المنبر الزمني (Chronological Decades Timeline)
بدلاً من حصر الصفحة في آخر 3 سنوات:
* **عقد الأربعينيات (1440 - 1448هـ):** مرحلة القضايا المعاصرة والبث عالي الدقة (HD/4K).
* **عقد الثلاثينيات (1430 - 1439هـ):** مرحلة التأسيس للمحاور الفلسفية وبرامج الفضائيات.
* **عقد العشرينيات (1420 - 1429هـ):** مرحلة البدايات الرقمية والتسجيلات الصوتية النقية.
* **الأرشيف التراثي والتاريخي (1406 - 1419هـ):** التسجيلات التاريخية المبكرة لسماحة السيد.

### ج. محرك التصفية المتعدد والفوري (Faceted Realtime Filtering)
فلترة فورية تدعم:
* **نوع المسار:** موسم سنوي / درس مستمر / حوار / برنامج
* **صيغة الوسائط:** مرئي (YouTube) / صوتي (MP3) / مفرغ نصياً (Transcript/PDF)
* **المكان / الدولة:** القطيف / النجف الأشرف / لندن / ديربورن / الكويت / أخرى
* **السنة الهجرية:** (1406 – 1448)

### د. مشغل السلسلة المترابط (Smart Course Player Layout)
عند فتح أي محاضرة تابعة لسلسلة (مثل درس التفسير رقم 15):
* ظهور مشغل الفيديو/الصوت والتفريغ النصي.
* قائمة جانبية ذكية تعرض جميع حلقات السلسلة ومؤشر الدرس الحالي مع إمكانية الانتقال للدرس التالي أو السابق تلقائياً.

## 4. خارطة طريق الاستيراد والدمج الآلي (Technical Migration Roadmap)

1. **إعداد الحقول الداعمة في جدول `media_items`:**
   * `series_type`: نوع المادة (موسم / درس حوزوي / برنامج فضائي / حوار).
   * `location`: مكان الإلقاء الموثق.
   * `episode_number`: رقم الحلقة أو الدرس في السلسلة.
2. **برمجة سكربت الاستيراد الذكي (Artisan / Python Command):**
   * قراءة ملف الإكسل ومعالجة البيانات والتواريخ الهجرية/الميلادية وربط روابط اليوتيوب والصوت.
3. **استيراد تجريبي (Dry-run Import):**
   * البدء بورقة عمل واحدة (مثل درس التفسير أو مواسم محرم) للتأكد من المظهر والسرعة وتجربة المستخدم قبل الاستيراد الشامل.
