## 3. المعمارية التقنية والتكامل (Technical Implementation)

### أ. ملفات الخط (Web Font Assets)
توجد ملفات الخط في المسار العام للموقع:
- `public/fonts/abo-thar.woff2` (حجم خفيف جداً: **64KB** للتحميل السريع في المتصفحات الحديثة).
- `public/fonts/abo-thar.woff` (75KB).
- `public/fonts/abo-thar.ttf` (113KB).

### ب. تعريفات CSS في قوالب الموقع
تم تضمين الخط عبر `@font-face` وفئة التنسيق `.symbol-abothar` في:
1. **واجهة الزوار العامة:** [app.blade.php](file:///c:/wamp/www/almoneer-gen/resources/views/layouts/app.blade.php)
2. **لوحة التحكم ومحرر النصوص:** [admin.blade.php](file:///c:/wamp/www/almoneer-gen/resources/views/layouts/admin.blade.php)
3. **أداة المخمة:** [vacum.blade.php](file:///c:/wamp/www/almoneer-gen/resources/views/admin/tools/vacum.blade.php)

```css
@font-face {
    font-family: 'AboThar';
    src: url('/fonts/abo-thar.woff2') format('woff2'),
         url('/fonts/abo-thar.woff') format('woff'),
         url('/fonts/abo-thar.ttf') format('truetype');
    font-weight: normal;
    font-style: normal;
    font-display: swap;
}

.symbol-abothar {
    font-family: 'AboThar', serif !important;
    display: inline-block;
    vertical-align: -0.1em;
    line-height: 1;
    font-size: 1.25em;
    margin: 0 0.18em;
    font-weight: normal !important;
}
```

## 4. وظائف الكلاس المطور `TranscriptFormatter`

يحتوي الكلاس [app/Services/TranscriptFormatter.php](file:///c:/wamp/www/almoneer-gen/app/Services/TranscriptFormatter.php) على المراحل الثلاث التالية:

1. **`cleanInlineText(string $text): string`**:
   - ينظف النصوص المنسوخة ويوحد كتابة الأدعية التكريمية إلى اختصارات قياسية: `(ع)`, `(عه)`, `(عع)`, `(ره)`, `(قده)`, `(دام ظله)`, `(ص)`.
   - يمنع الأقواس المتكررة (مثل `((دام ظله))` أو `((ع))`).
   - يحول الأرقام الهندية (٠-٩) إلى أرقام عربية قياسية (0-9).
   - يضبط علامات الترقيم والفواصل والنقاط المزدوجة والتنصيص «...».

2. **`format(?string $text): string`**:
   - يحول النص الخام أو كود HTML إلى كود غني متوافق مع معايير الموقع:
     - الآيات القرآنية بالخط العثماني باللون الأخضر المشرق `#09B182` بين أقواس `﴿...﴾` (دون مسافة فاصلة بين القوس وبداية/نهاية الآية).
     - العناوين الرئيسية `#990000` والعناوين الفرعية `#8B4513`.
     - القوائم النقطية `<ul>` و `<li>`.
     - استبدال الرموز بعناصر `<span class="symbol-abothar" title="...">A</span>` ورمز الصلاة النبوية التامة الفيكتور.

3. **`toCleanText(string $html): string`**:
   - التحويل العكسي: عند طلب استخراج النص المنقح من كود HTML، يعيد الرموز الخطية إلى علاماتها النصية الأصلية `(ع)`، `(عه)`، `(قده)`، إلخ، بدقة كاملة ودون تشويه للنص.

## 5. طريقة الاستخدام في لوحة التحكم (Admin Usage)

1. التوجه إلى لوحة الإدارة ⟵ **أدوات إدارة المحتوى** ⟵ **أداة المخمة (تنقيح النصوص)** على الرابط: `/admin/vacum`.
2. لصق النص المنسوخ من Word في تبويب **"لصق من Word"**.
3. النقر على زر **"خم وتنسيق النص الآن"**.
4. ستظهر المعاينة الحية الفورية بالرموز الخطية والآيات والعناوين، مع إمكانية:
   - **نسخ كود HTML للنشر** بنقرة واحدة ولصقه في المحاضرات أو المقالات.
   - **نسخ كنص منسق** للصقه في Word أو أي محرر آخر.
   - استعراض **النص المنقح** بالعلامات القياسية.
