## 🌟 المميزات والمحتويات

* **المحاضرات والمواسم السنوية:**
  * تنظيم متسلسل حسب السنوات الهجرية والمواسم (عاشوراء، صفر، شهر رمضان، الوفيات والمواليد).
  * توفير كل محاضرة بثلاث صيغ متكاملة:
    1. **فيديو مرئي:** مشغل YouTube ذكي بدون إعلانات وتأخير.
    2. **تسجيل صوتي:** مشغل مدمج بالموقع بصيغة MP3، أو تضمين مباشر من SoundCloud مع مشغل عائم يتنقل مع الزائر أثناء القراءة.
    3. **تفريغ نصي منقح ومطابق للطباعة:** عرض نصي scholarly بالخط العثماني للآيات، مع أزرار تكبير/تصغير الخط، ونسخ النص، وزر طباعة مخصص يخفي عناصر الموقع ويخرج مستنداً منسقاً يطابق ملفات الـ PDF الأصلية.
* **المؤلفات والكتب:** مكتبة رقمية للكتب الفقهية، العقائدية، والفكرية مع إمكانية التحميل المباشر وتصفح الفهارس.
* **ديوان الشعر:** عارض تفاعلي لقصائد سماحة السيد ببحورها الشعرية ومناسباتها.
* **الاستفسارات الشرعية والفكرية:** أرشيف إجابات سماحة السيد مصنفة فقهياً وعقائدياً.
* **معرض الصور والميديا:** ألبومات توثيقية للزيارات والأنشطة التبليغية في مختلف دول العالم.

## 🛠 التقنيات المستخدمة

* **إطار العمل (Backend):** Laravel 12 (PHP 8.2 / 8.3).
* **قاعدة البيانات:** SQLite (`database/database.sqlite`) لسرعة الأداء وسهولة النقل والنسخ الاحتياطي المستقل.
* **الواجهة الأمامية (Frontend):** Blade Templates، Tailwind CSS (مع خيارات الثيم الزمردي والثيم الفيروزي المشرق)، خطوط عربية فاخرة (IBM Plex Sans Arabic للواجهات، Amiri للنصوص العلمية والشعر، و Amiri Quran / KFGQPC Uthman Taha للآيات القرآنية).
* **إدارة الحزم:** Composer & NPM.

## 🌐 البنية التحتية واستضافة الخادم (Hetzner)

* **الخادم:** استضافة Hetzner المدارة (`195.201.6.46:222`).
* **استراتيجية العزل والحماية (Zero-Downtime Isolation):**
  * الموقع القديم ورسالة الصيانة تعمل في المجلد الرئيسي: `/usr/www/users/almonc/`.
  * التطبيق المطور تم وضعه في مجلد مستقل ومعزول تماماً: `/usr/www/users/almonc/almoneer_app/`.
  * يتم استعراض واختبار الموقع المطور عبر الرابط الفرعي: **`https://www.almoneer.org/home/`**
  * تم ربط الرابط عبر Symlink: `/usr/www/users/almonc/home` $\rightarrow$ `/usr/www/users/almonc/almoneer_app/public`.

## ⚙️ إعداد إصدار PHP عبر .htaccess (بالغ الأهمية)

على خوادم Hetzner المدارة (konsoleH)، يعمل خادم Apache الافتراضي على مستوى النطاق بإصدار قديم (PHP 5.6) للموقع القديم. ونظراً لأن متطلبات Laravel 12 تحتاج إلى `PHP >= 8.2`، تم ضبط ملف `public/.htaccess` بتوجيه مخصص يحقن **PHP 8.3 FastCGI** لمجلد التطبيق حصرياً:

```apache
<IfModule mod_fcgid.c>
    # تشغيل PHP 8.3 حصرياً لتطبيق المنير المطور عبر FastCGI
    Options +ExecCGI -MultiViews -Indexes

    <FilesMatch "\.php$">
        SetHandler fcgid-script
        FCGIWrapper /home/httpd/cgi-bin/php83-fcgi-starter.fcgi .php
    </FilesMatch>
</IfModule>

<IfModule !mod_fcgid.c>
    <IfModule mod_negotiation.c>
        Options -MultiViews -Indexes
    </IfModule>
</IfModule>

<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteBase /home/

    RewriteCond %{HTTP:Authorization} .
    RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]

    RewriteCond %{HTTP:x-xsrf-token} .
    RewriteRule .* - [E=HTTP_X_XSRF_TOKEN:%{HTTP:X-XSRF-Token}]

    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_URI} (.+)/$
    RewriteRule ^ %1 [L,R=301]

    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^ index.php [L]
</IfModule>
```

> **تنبيه:** هذا الملف محفوظ ومحدث داخل المستودع (`public/.htaccess`). عند عمل أي تحديث أو سحب من Git (`git pull`)، يتم الحفاظ عليه تلقائياً لضمان عدم توقف الموقع أو ظهور خطأ Composer Platform.

## 🔗 نظام الروابط المختصرة (Short URLs Scheme)

نظراً لاحتواء الروابط الدائمة (Canonical URLs) على كلمات عربية يتم تشفيرها تلقائياً بنظام (Percent-encoding) لتصبح طويلة جداً وتستهلك مساحة كبيرة في الطباعة وعلى وسائل التواصل مثل واتساب، تم اعتماد نظام روابط مختصرة ذكي وخفيف وسهل القراءة:

### جدول الروابط المختصرة:
| القسم | الرابط المختصر المباشر | الوجهة المستهدفة |
| :--- | :--- | :--- |
| **المحاضرات والمرئيات** | `https://almoneer.org/l/{id}` | `/lectures/{year}/{season}/{slug}` |
| **الكتب والمؤلفات** | `https://almoneer.org/b/{id}` | `/books/{slug}` |
| **الشعر والقصائد** | `https://almoneer.org/p/{id}` | `/poems/{slug}` |
| **الاستفتاءات الفقهية** | `https://almoneer.org/q/{id}` | `/inquiries/{slug}` |
| **الأخبار والنشاطات** | `https://almoneer.org/n/{id}` | `/news/{slug}` |

### آلية العمل والتحويل:
1. **التحويل من جذر النطاق (Root .htaccess):**
   تمت إضافة قواعد تحويل في `/usr/www/users/almonc/.htaccess` لتحويل الروابط من جذر الموقع مباشرة (مثل `almoneer.org/l/22`) إلى بوابة التطبيق (`/home/l/22`) مع كود تحويل دائم **HTTP 301**.
2. **التحويل داخل Laravel:**
   تستقبل الدالة `shortRedirect($id)` المعرف وتستعلم عن السجل النشط وتوجه المتصفح بـ `HTTP 301 Permanent Redirect` إلى الرابط الدائم الكامل، مما يحافظ على قوة تصنيف محركات البحث (SEO).
3. **التذييل في الطباعة (Print Footer Bar):**
   يظهر الرابط المختصر المدمج تلقائياً في أسفل الصفحات المطبوعة بصيغة نظيفة وموجزة: `almoneer.org/l/22`.
4. **أزرار المشاركة المباشرة:**
   تم تضمين زر "نسخ الرابط المختصر" وزر "مشاركة عبر واتساب" في شريط أدوات القراءة أعلى تفريغ المحاضرة.

## 🧹 أداة تنقيح وتفريغ المحاضرات (المخمة - Vacum Tool)

الأداة المسؤولة عن معالجة وتدقيق النصوص المفرغة المنقولة من Word أو قواعد البيانات السابقة:
* **المسار في لوحة التحكم:** `http://127.0.0.1:8000/admin/tools/vacum`
* **الفئة البرمجية المسؤولة:** `App\Services\TranscriptFormatter`
* **معمارية حفظ المدخلات النظيفة:** يتم حفظ النص في قاعدة البيانات (`media_items.transcript`) بصيغة **مدخلات التنسيق النظيفة** (`[t]`, `[c]`, `{...}`, `[poem]`, `[1]`, `الهوامش:`). يتيح ذلك تحرير المحاضرة مرات غير محدودة دون تشوه الرموز أو فقدان التنسيقات، بينما يتم توليد مخرجات HTML الجاهزة ديناميكياً عند المعاينة وفي صفحة العرض والطباعة عبر `TranscriptFormatter::format()`.

### قواعد التنظيف والتنسيق الآلي:
1. **معالجة النصوص المشفرة ومنع كسر الأسطر العارضة:**
   * إزالة علامات التفاف الأسطر العارضة (`\r\n` الناشئة عن التفاف الأسطر عند 70 حرفاً في Microsoft Word) من داخل الفقرات والقوائم، ومنع تحويلها إلى وسم `<br>`.
   * دمج أسطر العناوين المنكسرة والبصريات المنفصلة (مثل `المحور\nالأول:` $\rightarrow$ `المحور الأول:`).
2. **محاذاة وضبط الفقرات بالكشيدة (Kashida Justification):**
   * الحفاظ على مدات وتطويل الكشيدة العربية (`ـ`) داخل الفقرات النثرية لتوفير محاذاة رصينة ومريحة للعين من الحافتين (`text-align: justify; text-justify: kashida;`).
3. **الآيات القرآنية:**
   * تحويل `{الآية}` و `﴿الآية﴾` إلى الخط العثماني مع لون أخضر فاخر معتمد (`#09B182`) وحجم خط متناسق مع المتن.
4. **العناوين والمحاور الرئيسية:**
   * تمييز العناوين الكبرى وكلمة **«المحاور:»** باللون الأحمر الداكن الكلاسيكي (`#990000`) وبخط `Traditional Arabic` / `Amiri` العريض المعتمد للموقع بحجم مريح (1.35rem - 1.55rem).
   * العناوين الفرعية والمصاديق تظهر باللون البني المعتمد (`#8B4513`).
5. **القوائم النقطية للمحاور:**
   * تحويل `<ul>` و `<li>` والأسطر المبدوءة بشرطات `-` إلى نقاط بارزة `list-disc` مع تباعد متناسق وخط عريض، مطابقة لملفات الـ PDF الصادرة عن شبكة المنير.
6. **الصلوات والأدعية التكريمية (خط الأربعين Arb3een):**
   * استبدال العبارات التكريمية والصلوات بالنقوش الفنية المعتمدة لخط الأربعين (`arb3een.woff2`) عبر نقاط Unicode الخاصة (`U+F032` - `U+F050`)، وتفادي ظهور الحروف الإنجليزية القديمة.
7. **الشعر والأبيات العمودية:**
   * دعم الوسم `[poem] الشطر الأول | الشطر الثاني [/poem]`.
   * العرض عبر شبكة متناظرة من 3 أعمدة تفصل بين الشطرين بفاصل زخرفي `✤` دون شد أو تباعد قسري للكلمات.
8. **الهوامش المرجعية والمراسي (Footnotes & Anchors):**
   * تحويل `[1]` في المتن إلى مراجع علوية ذكية تعمل بروابط متوافقة مع النطاق الرئيسي والمجلدات الفرعية (`url()->current() . '#fn-1'`) والتمرير السلس.
   * تجميع نصوص الحواشي تلقائياً في صندوق سفلي مخصص للهوامش في نهاية المحاضرة.

## 🚀 طريقة النشر والمزامنة مع الخادم الحي (Deployment)

لإرسال وتطبيق التحديثات على الخادم دون التأثير على استقرار الموقع:

```bash
# 1. حفظ التغييرات ودفعها إلى GitHub
git add .
git commit -m "Your descriptive commit message"
git push origin main

# 2. تشغيل سكربت النشر الآمن عبر بايثون
python scratch/deploy_to_server.py
```

يقوم السكربت آلياً بـ:
1. الاتصال الآمن بالخادم عبر SSH على المنفذ `222`.
2. إنشاء نسخة احتياطية فورية من قاعدة البيانات (`storage/backups/db_{TIMESTAMP}.sqlite`).
3. سحب آخر التعديلات من Git (`git pull origin main`).
4. التأكد من سلامة ملف `.htaccess` الخاص بـ FastCGI PHP 8.3.
5. تشغيل هجرات قاعدة البيانات في حال وجودها (`php artisan migrate --force`).
6. تفريغ كاش القوالب والتطبيق (`php artisan view:clear && cache:clear`).
7. فحص حالة الروابط الحية والتأكد من إرجاع كود `200 OK`.

## 🖋️ نظام الرموز التكريمية وخط الأربعين (Religious Honorifics & Arb3een Font)

تم دمج خط **الأربعين (`Arb3een` / `arb3een313-L`)** كخط ويب فكتور متكامل (`public/fonts/arb3een.woff2`, `arb3een.woff`, `arb3een.ttf`) لاستبدال الأدعية والصلوات التكريمية الـ 12 آلياً عند نشر وتنسيق المحاضرات والمقالات عبر أداة **«المخمة»** (`TranscriptFormatter`):

* **(ص) / صلى الله عليه وآله وسلم** $\rightarrow$ رمز `U+F032` في خط الأربعين.
* **(ع) / عليه السلام** $\rightarrow$ رمز `U+F034` في خط الأربعين.
* **(عه) / عليها السلام** $\rightarrow$ رمز `U+F035` في خط الأربعين (نقش "عليها السلام").
* **(عما) / عليهما السلام** $\rightarrow$ رمز `U+F036` في خط الأربعين (نقش "عليهما السلام").
* **(عع) / عليهم السلام** $\rightarrow$ رمز `U+F037` في خط الأربعين (نقش "عليهم السلام").
* **(عج) / عجل الله تعالى فرجه الشريف** $\rightarrow$ رمز `U+F049` في خط الأربعين.
* **(قده) / قدس سره الشريف** $\rightarrow$ رمز `U+F042` في خط الأربعين.
* **(دام ظله) / دام ظله الوارف** $\rightarrow$ رمز `U+F04B` في خط الأربعين.
* **(ره) / رحمه الله** $\rightarrow$ رمز `U+F045` في خط الأربعين.
* **(رض) / رضي الله عنه** $\rightarrow$ رمز `U+F050` في خط الأربعين.
* **(طاب ثراه) / طاب ثراه** $\rightarrow$ رمز `U+F04F` في خط الأربعين.
* **(مد ظله) / مد ظله العالي** $\rightarrow$ رمز `U+F04C` في خط الأربعين.

للتفاصيل الفنية الكاملة وجداول الأنماط البديلة، راجع: **[docs/TRANSCRIPT_VACUM_AND_SYMBOLS.md](docs/TRANSCRIPT_VACUM_AND_SYMBOLS.md)**.
